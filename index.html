The Grazioso Salvare application was originally developed during CS 340: Client/Server Development at Southern New Hampshire University. The project uses Python and MongoDB to manage animal shelter records and help identify animals suitable for different types of rescue training.

Original Functionality

The original application includes a Python CRUD module that communicates with MongoDB and an interactive dashboard for displaying animal shelter information. Enhancement One: Software Engineering and Design

Artifact Overview

For my first CS 499 enhancement, I selected the Grazioso Salvare dashboard originally developed during CS 340: Client/Server Development. The application uses Python, MongoDB, and Dash to display animal shelter records and help users identify animals suitable for rescue training.

Enhancements Made

The original application worked, but much of its functionality was closely connected to the dashboard code. I improved the application by separating responsibilities into different modules. The CRUD module handles database operations, the rescue service handles filtering logic, and the dashboard focuses on presenting data and handling user interaction.

I also added a configuration module to manage database settings through environment variables instead of hard-coding credentials into the application. Additional improvements included input validation, more specific exception handling, and automated unit tests.

Another improvement involved changing how the dashboard accesses animal information. Instead of relying on numbered DataFrame columns, the enhanced version accesses fields such as breed, name, and location by name. This makes the application easier to understand and maintain.

Challenges and Lessons Learned

One of the challenges was improving the structure of an existing application without changing its intended functionality. I also encountered compatibility and dependency issues when working with Dash and JupyterDash in a different development environment.

This enhancement reinforced the importance of separation of concerns, testing, maintainability, and understanding the difference between application problems and environment-related issues.

Course Outcomes

This enhancement primarily supports Course Outcomes Four and Five by demonstrating maintainable software design, appropriate development techniques, improved configuration management, input validation, and more controlled error handling.

It also supports Course Outcome Three through the design decisions involved in separating application responsibilities and evaluating software architecture.

Enhancement Two: Algorithms and Data Structures

Artifact Overview

For my second CS 499 enhancement, I expanded the Grazioso Salvare application's rescue filtering functionality. The original application identified animals using predefined characteristics, but it did not rank candidates according to how closely they matched rescue-training needs.

Enhancements Made

I developed a weighted scoring algorithm that evaluates animal records using breed, age, and sex. Preferred breeds receive 40 points, animals within the preferred age range receive 30 points, and matching sex characteristics receive 20 points.

Each rescue category has its own criteria. Animals receiving at least 50 points qualify for ranking. This provides more information than a basic matching filter because candidates can be compared according to their suitability scores.

Priority Queue Implementation

I used Python's heapq module to implement a priority queue. The algorithm calculates each animal's suitability score, inserts qualifying candidates into the queue, and retrieves them in descending score order.

The priority queue uses negative scores because Python's heapq implements a min-heap. This allows the highest-scoring candidate to be retrieved first. Original record order is preserved when candidates have equal scores.

Design Decisions and Benefits

The scoring system makes rescue-candidate evaluation more flexible and useful. Instead of treating all matching animals equally, the application identifies stronger candidates based on multiple weighted characteristics.

The implementation also separates candidate evaluation from the dashboard, making it easier to adjust scoring criteria or test the algorithm independently.

Testing

Automated unit tests verify full and partial suitability scores, candidate ranking order, minimum qualification requirements, and handling of missing age information.

Course Outcomes

This enhancement primarily supports Course Outcome Three through algorithm design, data-structure selection, and evaluation of implementation trade-offs.

It also supports Course Outcome Four by applying Python's priority queue functionality to a practical problem involving animal shelter data.
